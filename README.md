# Pong GS — GitHub Pages

Цей репозиторій автоматично збирає гру LÖVE у браузерну версію через LÖVE.js та публікує її на GitHub Pages.

## Як встановити

1. Завантажте вміст цієї папки в корінь репозиторію GitHub із гілкою `main`.
2. Переконайтеся, що файл workflow лежить саме тут: `.github/workflows/pages.yml`.
3. Відкрийте **Settings → Pages**.
4. У полі **Build and deployment → Source** виберіть **GitHub Actions**.
5. Відкрийте вкладку **Actions**, виберіть **Build and Deploy Pong GS** і дочекайтеся зеленого статусу.
6. Після успішного завершення відкрийте адресу GitHub Pages, яку покаже розділ **Settings → Pages**.

Після кожного push у `main` сайт автоматично перебудовується.

## Керування

- Гравець 1: `W` / `S`
- Гравець 2: `↑` / `↓`
- `Enter`: почати гру / подати м'яч / продовжити
- `Space` або `Esc`: пауза
- `R`: перезапуск
- `M`: звук увімкнути/вимкнути

Гра завершується, коли один із гравців набирає 10 очок.
